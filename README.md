##### **Task 9: Student Records Using Python Lists**

##### 

###### **Description**



This project is a simple Python program that stores student names and marks using lists. It allows users to search for a student, sort student records based on marks, and find the highest and lowest scores.



###### **Objective**



To practice Python lists and improve my skills in searching, sorting, and handling student records.



###### **Technologies Used**



* Python 3
* Lists
* Loops and conditional statements
* Built-in functions



###### **Features**



* Store student names and marks.
* Display all student records.
* Search for a student by name.
* Sort students according to their marks.
* Find the highest and lowest scores.
* Display the names of students with the highest and lowest marks.



###### **How to Run**



1\. Install Python 3 on your computer.



2\. Save the program as "student\_records.py".



3\. Open a terminal or command prompt.



4\. Run the following command: python student\_records.py



5\. Enter the number of students, their names, and marks when prompted.



###### **Learning Outcome**



Through this task, I practiced using Python lists, loops, searching, sorting, and built-in functions to manage student records.



###### **Conclusion**



This task helped me understand how Python lists can be used to store and process data efficiently through a simple student records program.
